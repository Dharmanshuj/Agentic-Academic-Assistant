2.2  Core  Features    
2.2.1  Authentication  System    
The  platform  ensures  that  authentication  and  authorization  operations  are  secure  by  leveraging  
the

along

[9].

Roles  supported  on  the  platform  are:

The  platform  includes  an  easy-to-use  problem  management  system  where  educators  can  manage  
problems,

and
 
other

such

1.  Time  constraints   2.  Memory  constraints   3.  Public  and  hidden  testcases   4.  Weighted  grading  schemes   5.  Visibility  options   This  allows  assignments,  lab  classes,  and  programming  sessions.

Grants  Dashboard  is  an  online  centralised  financial  management  system  that  helps  automate  the  
processes

finances

The  online  system  is  built  in  such  a  way  that  allows  the  administration  to  organise  grant  financial

online

Information

:

institutions
 
track
